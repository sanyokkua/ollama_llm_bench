Provider Edit sub-dialog — Test reachability + Test inference panel

Visual reference for 06_Settings_Dialog/sub_dialogs/provider_edit.md §8. The footer exposes two distinct actions — Test reachability (LLMClient.probe_health(); never billable; never an inference) and Test inference (LLMClient.test_inference(model_name); one short canned chat call against the named model; potentially billable on paid providers). The user MUST select or enter a model name before the Run inference test button enables.

Import preview modal (opens on Import… before anything is written)

After the user picks a YAML file, this modal previews exactly what the import will do and requires confirmation before any write (`10_Domain_and_Data/06_IMPORT_FORMATS.md` §8). It lists each provider as Add / Update / Skip, summarises recognised vs ignored setting keys, and surfaces any hard errors. Apply is disabled while a hard error is present.
