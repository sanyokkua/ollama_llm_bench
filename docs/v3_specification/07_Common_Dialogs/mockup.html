Common Dialogs — visual mockup gallery

All seven modal dialogs of Ollama LLM Bench, reachable from anywhere in the application. Each is shown in its primary state; the validating, mode-aware, and gate-aware dialogs include key variant states. Button order follows 08-L §5: side actions on the left, the back-out action and then the right-most primary on the right. Colours, glyphs, and status names are the canonical ones from 08-L and 10_Domain_and_Data/02_DTOS_AND_ENUMS.md.

2 · Run Summary dialog (pre-start confirmation, mode-aware)

The dialog adapts its sections to the selected run mode. SYNTHETIC shows the synthetic prompt matrix and no task files; TASKS shows task files and an optional judge; GRADED shows task files plus a required judge and an embedding section. Every variant lists the per-run snapshot of overridable flags. The GRADED variant is shown first in full; the SYNTHETIC and TASKS variants are shown side by side below.

Task selection is inline in this dialog (no separate "Pick Rows to Retry" step): not-yet-completed tasks are pre-checked, completed tasks are tickable to force a re-run, and Resume re-runs exactly the checked tasks. Resume Run is disabled while an unconfirmed BLOCKING drift warning is present; ticking "Resume anyway" enables it. WARNING drift never gates the button; settings differences are not drift (DD-57) and produce no row. The standalone Retry Selection dialog (panel 4) is reached only from the Resume widget's Retry row action.

5a — recoverable

✕Save failed
Could not write the settings to the local database. The settings were not saved; you can try again.
DatabaseLockedError: a SQLite write was blocked past the busy timeout correlation_id: 7f2a-c019

5b — action available

✕Provider authentication failed
Provider OpenAI Cloud rejected the credential. Open Settings to correct the API key, then start the run again. (The display name shown here is the SNAPSHOT name from the run-data row per DD-33; the internal provider_id is not displayed in the user-facing message.)
ProviderAuthError: provider rejected the credential provider_id: 2a9d7e22-7c64-4d39-803b-3f0a91c14b88 · http_status: 401

5c — fatal (forces exit; no Close)

✕The application cannot start
The local database could not be opened. The application cannot start. Move or remove the file below, then launch the application again.
DatabaseIntegrityError: schema invariant broken File: ~/Library/Application Support/OllamaLLMBench/ollama_llm_bench.sqlite

Blocking errors are raised through the Notification Service. The error category from the error taxonomy decides the pattern; a programmer error bypasses this dialog and reaches the process-terminal crash dialog instead.

7 · Generate Analysis dialog (analysis-model picker)

Opens from the Result Widget's Run Analysis tab when the user clicks the dynamic-label Generate / Regenerate analysis button. Title and primary button label both change between Generate and Regenerate based on whether the run already has a run_analysis body. Two field rows — Provider and Model — backed by the shared ui/shared/provider_dropdown and ui/shared/model_dropdown widgets (consumer-wired). The Model dropdown filters to chat-capable, non-embedding models. The dialog is bound to the application-wide single-inference gate: while another activity holds it, the Confirm button is disabled and an inline busy message is shown.
