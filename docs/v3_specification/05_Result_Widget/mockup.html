Run Analysis tab (generated state) — the single consolidated run_analysis narrative, rendered in full with no length cap. Copy and the dynamic-label Generate/Regenerate button sit in the in-tab toolbar (not file actions); the footer cluster is Export Markdown only. The toolbar button label is state-dependent: it reads Generate analysis when the selected run has no run_analysis yet, and Regenerate analysis (shown above) once one exists (SPEC-054). Empty (not-generated) state: when run_analysis is absent the metadata line is hidden and the body shows a centred muted message instead of the narrative — "Run-level analysis is generated when the benchmark finishes." while the run is still running, or "Run-level analysis was not requested for this run. Click Generate analysis to produce it now." for a finished run whose snapshot had the toggle off; the toolbar button then reads Generate analysis (see tabs/run_analysis_tab.md §9).
Uniform footer contract — identical layout on every tab.
The left cluster holds the export buttons for the active tab's content kind: Summary and Details → Export CSV + Export Markdown · Charts → Export PNG + Export SVG · Run Analysis → Export Markdown.
The right cluster is always the same pair — the toggle Save to app data folder bound to ui.export_save_directly. When ON, the Open Exports Folder button is shown and every export writes straight to <app-data>/exports/. When OFF, the button is hidden and every export opens a Save Picker defaulted to the Desktop.

View-only-during-run rule. While any run is in a non-terminal state, every Export button and the Regenerate button are disabled with the tooltip "Disabled — a benchmark is in progress." The run selector, tab switching, filtering, sorting, detach, Copy, and chart navigation stay enabled.

Run selector. The header holds only the run-selector dropdown — no run-management actions. Rename, delete, retry, and clone live in the Resume tab. The dropdown auto-selects a newly started run on its first appearance, then respects a deliberate manual selection.
