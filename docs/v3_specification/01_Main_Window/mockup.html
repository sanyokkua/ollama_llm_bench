Annotations

  • Title bar reads Ollama LLM Bench v{version} at idle, and Ollama LLM Bench - Running: {run_name} or - Paused: {run_name} while a run is active.
  • Menu bar — corrected. The menu bar carries only the Settings action, the About action, the workspace switcher, the running pill, and the version string. There is no File / Edit / View / Help dropdown. Quit is the window close (X) control; Task Editor file operations live on the Task Editor toolbar; folder-open actions live in the About dialog.
  • Settings action opens the Settings dialog. It is shown disabled, with an explanatory tooltip, while a benchmark run is in a non-terminal state.
  • About action opens the Application Information dialog (version, project links, and the App folder / Run Logs / App Logs buttons).
  • Workspace switcher is a two-segment control, always visible; it swaps the workspace region between the Benchmark and Task Editor workspaces.
  • Running pill is present only while a run is non-terminal; clicking it switches to the Benchmark workspace and focuses the Progress widget.
  • Splitter has three children with minimum widths 320 / 480 / 480 px; handles are 1 px and children cannot be collapsed to zero. Sizes persist via ui.splitter_sizes.
  • Running layout (Frame 2): the left panel is removed entirely and the centre Progress panel expands; Stop or run completion restores the idle three-panel layout (Frame 1), Pause does not.
  • Status bar: the left health dot plus label is clickable in the Benchmark workspace — it opens Settings / Providers and re-probes; the click is ignored with a toast while a run is non-terminal. The centre region shows transient toasts; the right shows the version.
