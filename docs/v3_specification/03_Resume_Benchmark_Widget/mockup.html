The Resume Summary dialog (07_Common_Dialogs/) opens before any resumed task runs. It surfaces the Run Drift Detector output (11_Services_and_Algorithms/11_RUN_DRIFT_DETECTOR.md): a Blocking warning gates the Resume button behind the “Resume anyway” acknowledgement; a Warning is informational (an availability check that could not be completed). Every warning reports an environment-availability failure of the run’s frozen configuration (DD-57); settings differences are not drift. The task picker pre-checks every result that is not fully completed — pending, in-flight, and retryable-failure rows; a completed result is left unchecked but can be re-run by the user explicitly checking it.
