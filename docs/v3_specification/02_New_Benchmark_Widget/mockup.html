Start button — validation states

The sticky Start button reflects the Run Validator (description.md §6). It is disabled while any hard error is present and enabled otherwise; soft warnings never disable it. The validation messages appear in the button's hover tooltip; they are drawn here as visible callouts because a mockup cannot show hover.

Start — disabled (hard errors)
⚠ Fix the following to start this run:
  • Select at least one test model
  • Add at least one task file
  • A judge model is required when the judge phase is on
Disabled because the configuration has hard errors. The same list is the button's hover tooltip (08-L §10).
Start — enabled (soft warnings only)
Review before starting:
  • One selected model has unconfirmed streaming (TTFT may be missing)
  • A task file contains 0 parsed tasks and will be skipped
Enabled — soft warnings do not block Start; the warnings are shown in the tooltip so the user can proceed informed.
