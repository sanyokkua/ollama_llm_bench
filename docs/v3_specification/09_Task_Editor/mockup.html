Task Editor — full-window workspace

The Task Editor is the application's second workspace. It replaces the Benchmark workspace layout when the workspace switcher in the menu bar is set to Task Editor. Three panes — Files, Tasks, Field editor — plus an optional read-only YAML preview. Drag-drop of .yaml / .yml files and folders is accepted across the whole window. A running benchmark shows as a clickable Running pill in the menu bar.

2 · Help popover — opens on hover or click of an i icon

Each help icon opens a popover whose content is rendered from field_reference.md; the same text appears everywhere the editor renders that field.
field · task_id
Required. The unique identifier of the task within its file. It is the stable join key against every benchmark result row.

Format · lowercase snake_case, ASCII letters, digits, underscores, maximum 80 characters.
Validation
  • Empty → hard error (the file cannot save)
  • Duplicate within the file → hard error on every sharing row
  • Not snake_case, or over 80 chars → soft warning

Save All writes only the 1 saveable file; the file with a hard error is kept open so you can fix or discard it.

Triggered on workspace-leave, file-close, or app-quit while any buffer is dirty (state_machine.md §1 ConfirmLeave / ConfirmQuit, §3 ConfirmClose). Save All writes only files free of hard errors and reports any it cannot save; Discard All drops every unsaved edit; Cancel returns to the editor with all buffers intact. A leave/quit with no dirty buffer proceeds with no dialog.

8 · Parse-error banner — reload hit malformed YAML

data_extraction.yaml · parse error
✕ data_extraction.yaml could not be parsed on reload — malformed YAML at line 14. Your previous in-memory model is unchanged and still shown.
3 files open · 1 parse error

A reload that encounters malformed YAML aborts: the prior in-memory model is kept (no data loss), the file shows the × error glyph, and a banner names the failure. The user fixes the file externally and Reloads, or Closes the file (state_machine.md §3 ParseError).

Workspace switcher — the segmented control in the menu bar is the only way to swap workspaces; click a segment to switch. The active workspace persists to ui.active_workspace across launches.

Running pill — shown only while at least one benchmark run is in a non-terminal state. Clicking it switches to the Benchmark workspace and focuses the Progress widget.

Severity badges — × hard errors disable Save for that file (empty task_id / question / golden_answer, duplicate ids, malformed YAML). ! soft warnings still save (empty grading criteria, non-canonical snake_case). i soft info is advisory only (e.g. a very long prompt). ● marks a file with unsaved edits.

Mouse-only operation — every editor action is exposed as a toolbar button, a pane control, or a context-menu item; there are no keyboard shortcuts or accelerators.
