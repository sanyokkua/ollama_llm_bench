Stability indicator legend

OK — the model has no consecutive maximum-timeouts; the provider circuit breaker is closed and responsive.
Warning — the model has 1 to (threshold − 1) maximum-timeouts, or the provider has 1–2 recent failures, or the breaker is half-open (probing).
Critical — the model reached the exclusion threshold, or the provider circuit breaker is open.
Source — Adaptive Timeout Service and Provider Circuit Breaker; live via the _model_stability_changed event.
