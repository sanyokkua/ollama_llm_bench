# Mockup conformance review

<!--
The verdicts in this document are unreviewed placeholders. This scaffold
records the required structure -- one checklist table per screen per theme --
so the coverage test can pass before the actual visual review has happened.
Every "conforms" cell below is provisional until a later pass replaces it with
a real observation made by looking at the capture beside its mockup.
-->

Each screen the specification's screen index lists is rendered by the offscreen
screenshot harness in both themes and reviewed here against that screen's
`mockup.html`, using the standardization review checklist.

Regenerate the captures with `just screenshots`; they land in
`artifacts/screenshots/light/` and `artifacts/screenshots/dark/` (git-ignored).

The mockup is the visual source of truth: where a capture and its mockup
disagree on a visual detail, the mockup is right. This document records what was
observed. It never changes a widget -- a real discrepancy becomes its own story.

Verdicts: `conforms`, `discrepancy`, `not-applicable`. Any `discrepancy` row
must say what differs in Notes.

## Follow-ups

Every `discrepancy` recorded across all nine screens (both themes), for a later story to pick
up. This story fixes none of them. Two root causes each explain several screens' worth of
findings and are grouped once rather than repeated per screen.

**Root cause 1 — 19 of the 22 dynamic-property `role=` values widget code sets have no QSS
selector.** `ui/theme/_internal/stylesheet_builder.py` styles only `role="primary-button"`,
`"filter-chip-active"`, and `"destructive-button"`; every other role falls back to native Qt
widget styling instead of the mockup's rounded/muted/outlined look. Affects:

- Screen 01 (Light & Dark) — Settings/About menu actions and the Benchmark/Task Editor
  workspace switcher render as plain default buttons instead of borderless menu-action links
  plus a rounded, primary-filled active segment (`role="menu-action"`, `"segmented-control"`,
  `"running-pill"` unstyled).
- Screen 02 (Light & Dark) — the "Mode" panel's active-row highlight and both panels'
  section-title styling don't appear (`role="mode-selector-row"`, `"section-title"` unstyled).
- Screen 05 (Light & Dark) — filter chips ("Models 4/4" etc.), "Clear filters", "Columns",
  "Detach", the Run Analysis "Copy" button, and muted-caption/warning-callout labels render as
  flat native boxes instead of styled chips/buttons (`role="outlined-muted-button"`,
  `"muted-caption"`, `"warning-callout"` unstyled).
- Screen 06 (Light & Dark) — "Reset to Defaults"/"Import…"/"Export…"/"Close"/"Test Embedding"
  and the "Embedding model" section heading render as plain flat controls
  (`role="outlined-muted-button"`, `"section-title"` unstyled).
- Screen 07 (Light & Dark) — "Copy Details"/"Cancel"/"Use default"/"Select all"/"Clear
  all"/"Check all visible"/"Uncheck all visible"/"Fix in Settings" across all seven dialogs, the
  Error dialog's × glyph, and About's copy/open-folder icon buttons all render unstyled
  (`role="outlined-muted-button"`, `"error-icon"`, `"icon-button"` unstyled).

**Root cause 2 — hand-painted `QStyledItemDelegate` row-action glyphs carry no tooltip or
accessible-name mechanism at all.** Affects:

- Screen 03 (Light & Dark) — Resume Benchmark's per-row rename pencil and "⋯" more-actions
  glyphs (`ui/resume_benchmark/_internal/row_actions_delegate.py`).
- Screen 06 (Light & Dark) — Settings Providers table's Enabled-column checkbox and
  hover-revealed Test (⚡)/More (⋯) glyphs
  (`ui/settings_dialog/_internal/providers_tab/row_actions_delegate.py`).

- Screen 02 (Light & Dark) — the "Mode" and "Test Models" panels have no section-title `QLabel`
  at all, unlike the mockup.

  disable with no explanatory tooltip.

  models" instead.
