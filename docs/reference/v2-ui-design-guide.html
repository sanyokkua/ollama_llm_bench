Ollama LLM Bench v2.0 — UI/UX Design Guide

Color palette, design tokens, QSS rules, widget reference, and full interactive mockups for all application states. PySide6-compatible only — no browser-only CSS.

For Claude Code: This document defines every color, spacing, and widget style. Use the QSS mapping tables to generate ui/style/tokens.py and ui/style/theme_dark.qss / theme_light.qss. Every hex value, radius, and padding here is the canonical source of truth.
PySide6 constraints: No CSS gradients with stops, no box-shadow, no transition, no opacity property, no :hover pseudo on non-interactive widgets. QSS supports: background, color, border, border-radius, padding, margin, font-size, font-weight, font-family, min-height, min-width, max-height, max-width. Sub-controls: ::drop-down, ::down-arrow, ::chunk, ::handle, ::indicator, ::tab, ::pane, ::section.

9. Implementation Rules for Claude Code

These rules are for the AI agent implementing the UI. They encode the design decisions from this guide into machine-parseable constraints.

File Structure

ui/
  style/
    tokens.py          # DARK, LIGHT, SHARED dicts
    theme_dark.qss     # QSS template with {token} placeholders
    theme_light.qss    # QSS template with {token} placeholders
    theme_loader.py    # Reads QSS, replaces {tokens}, applies to QApp

Naming Conventions for QSS Properties

  • Use setProperty("role", "primary") for button variants: "primary", "secondary", "danger", "icon"
  • Use setProperty("role", "secondary") for secondary QLabels
  • Use setProperty("role", "heading") for section heading QLabels
  • Use setProperty("role", "title") for panel title QLabels
  • Use setProperty("size", "small") for compact buttons
  • Use setProperty("verdict", "pass") or "fail" for verdict badges
  • Use setProperty("health", "live"), "down", "unknown" for health dots
  • After setting a property, call widget.style().unpolish(widget); widget.style().polish(widget) to reapply QSS

Color Rules

  • Never hardcode hex colors in widget code. Always reference tokens from tokens.py.
  • PASS = success color (#34D399 dark / #059669 light). FAIL = failure color (#F87171 dark / #DC2626 light).
  • Scores 0.00–1.00 everywhere. Never display 0–100 scale. The setting key ui.score_format controls whether 0.78 or 78% is shown, but the value is always stored as 0.00–1.00.
  • Chart colors cycle: primary (#14B8A6) for top items, accent (#A78BFA) for middle, failure (#F87171) for bottom/failing items.
  • Resolution layer colors: L1 = failure, L2 = warning, L3 = accent, L4 = primary.

Layout Rules

  • Three panels via QSplitter(Qt.Horizontal): Left (280px default, 250px min), Center (flex), Right (440px default, 380px min).
  • Minimum window size: 1200 x 700 px.
  • Panel padding: 16px all sides.
  • Section gaps: 16px between sections, 8px between widgets within a section.
  • All scrollable areas use QScrollArea with 8px-wide styled scrollbar.
  • Splitter handle: 5px wide, border color, hover = primary color.

Interaction Rules

  • During benchmark run: Left panel controls are disabled (opacity via QSS :disabled). Only Pause and Stop are active.
  • Pause button: toggles between "Pause" and "Resume" text. Color switches to warning when paused.
  • Table row selection: summary table selection filters detailed table. Use selection-background-color from tokens.
  • Log auto-scroll: enabled by default. Disable when user scrolls up. Show "Jump to bottom" button (QPushButton, fixed position at bottom of log area).
  • Drag-and-drop: Active state = border changes to primary color, dashed 2px. Background tints with primary at low opacity (use separate QSS class).
  • Streaming text: append to QTextEdit at max 20 Hz. Do NOT call append() per token.

Widget-Specific Rules

  • ProgressWidget: QFrame containing: QLabel (stage badge), QProgressBar, QLabel (ETA), QLabel (provider + health dot), QLabel (model), QLabel (task). Each field updates independently.
  • LogWidget: QScrollArea containing QVBoxLayout of LogEntry QFrames. Each LogEntry has a left border (3px, colored by entry type). Collapsible sections use QFrame with show/hide toggle.
  • ProviderCard: QFrame with QHBoxLayout: health dot + QVBoxLayout(name, url, models) + badge + buttons. Border turns red when health = down.
  • BadgeLabel: QLabel with fixed padding, border-radius 10px, background/color from verdict property. Use setProperty("verdict", "pass") and style via QSS.
  • ChartWidget: QPainter-based. Draw bars with painter.fillRect(). Use token colors from Python dict. No external charting library required for MVP — simple bar charts only.
